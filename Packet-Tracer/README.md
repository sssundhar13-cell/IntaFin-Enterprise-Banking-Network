# Cisco Packet Tracer Project Files

## Main simulation

- IntaFin_Cisco_project_WAN_Network.pkt — main multi-site banking network simulation created in Cisco Packet Tracer.

## Opening the file

1. Install Cisco Packet Tracer 9.x.
2. Open the .pkt file in Packet Tracer.
3. Inspect site topologies, device interfaces, VLANs, routing and security policies.
4. Refer to the root README and Network-Design, Configurations and Testing-Validation folders.

The saved Packet Tracer simulation is the source of truth for the current topology and device configuration. Verify live device state before treating a documented design goal as fully operational.
